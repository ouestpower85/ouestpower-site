OUESTPOWER — DOSSIER DU SITE INTERNET

CONTENU
- index.html : toutes les sections du site
- style.css : design responsive, mobile et ordinateur
- script.js : menu mobile, recherche de véhicule et formulaire e-mail

OUVRIR LE SITE
Ouvrir index.html dans un navigateur. Une connexion Internet est nécessaire pour charger les polices et les photos d’ambiance.

PUBLICATION GRATUITE AVEC GITHUB PAGES
1. Connectez-vous à GitHub et ouvrez le dépôt utilisé pour Ouestpower.
2. Dans le dépôt, utilisez Add file > Upload files (sur téléphone, ouvrir le menu + ou passer en affichage ordinateur si nécessaire).
3. Téléversez les trois fichiers index.html, style.css et script.js à la racine du dépôt. Si vous avez un dossier assets, il n’est pas nécessaire pour cette version.
4. Validez avec Commit changes.
5. Dans Settings > Pages, sélectionnez Deploy from a branch, la branche main et le dossier /(root), puis Save.
6. Attendez la publication et ouvrez l’adresse GitHub Pages affichée dans Settings > Pages.

À SAVOIR
- Les photos de la galerie sont des photos d’ambiance distantes, pas des photos de clients Ouestpower. Il faut les remplacer par les photos dont vous avez les droits avant de présenter la galerie comme un portfolio de réalisations.
- Le lien Instagram utilisé est https://www.instagram.com/ouestpower/ ; vérifiez qu’il correspond exactement au compte public.
- Le formulaire prépare un e-mail via l’application de messagerie du visiteur. Pour un formulaire qui envoie sans ouvrir l’e-mail, il faudra connecter un service de formulaire externe.
- Le sélecteur véhicule contient des exemples de motorisations et des valeurs illustratives, non vérifiées pour toutes les variantes. À valider avec une base technique fiable avant d’en faire un outil commercial. Les valeurs ne sont pas garanties.
- La conformité réglementaire des modifications moteur et de la conversion E85 doit être vérifiée au cas par cas. Ne pas présenter une conversion comme homologuée si elle ne l’est pas.
