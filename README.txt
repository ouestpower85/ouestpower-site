OUESTPOWER — SITE COMPLET POUR GITHUB PAGES

Fichiers :
- index.html : page complète
- style.css : design responsive
- script.js : menu, estimateur et formulaire de demande
- assets/ : photos d'accueil et réalisations

INSTALLATION :
1. Extraire ce ZIP sur l'ordinateur.
2. Dans le dépôt GitHub ouestpower-site, choisir Add file > Upload files.
3. Téléverser le contenu extrait en gardant la structure et le dossier assets.
4. Commit changes, puis attendre quelques minutes.
5. Actualiser https://ouestpower85.github.io/ouestpower-site/ avec Ctrl+F5.

La photo bmw-m2.jpg est utilisée uniquement en accueil, pas dans les réalisations.
Le formulaire prépare un message que le client peut copier et envoyer par Instagram.
GitHub Pages est un hébergement statique : pour une transmission automatique du formulaire, il faudra connecter ultérieurement un service de formulaire.
Les gains affichés sont indicatifs et non garantis. Vérifier la compatibilité, l'état mécanique et les règles applicables.
