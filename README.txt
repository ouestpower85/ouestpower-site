MISE EN LIGNE SUR GITHUB PAGES
1. Extraire le ZIP sur l'ordinateur.
2. Dans le dépôt GitHub ouestpower-site, ouvrir Add file > Upload files.
3. Envoyer index.html, style.css, script.js et le dossier assets avec son contenu.
4. Cliquer sur Commit changes.
5. Attendre quelques minutes puis actualiser le site.
