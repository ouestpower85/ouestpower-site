OUESTPOWER — SITE INTERNET COMPLET (VERSION ESTIMATEUR MARQUES / MODÈLES)

Contenu du dossier :
- index.html : site complet
- style.css : mise en forme
- script.js : menu, estimateur et demande en ligne
- assets/ : photos déjà présentes dans le site

Estimateur :
1. Choisir une marque.
2. Choisir un modèle.
3. Choisir la motorisation proposée.
4. Choisir Stage 1 ou projet FlexFuel E85.
5. Cliquer sur « Estimer les gains ».

Les gains sont des fourchettes indicatives de démonstration et ne sont pas garantis. Ils doivent être vérifiés selon l'année, la version exacte, l'état mécanique, le calculateur et la calibration. Pour les véhicules absents de la liste, demander une étude personnalisée. Le choix FlexFuel n'annonce aucun gain de puissance et affiche une demande de vérification de compatibilité.

PUBLICATION SUR GITHUB PAGES
1. Décompresser ce ZIP sur l'ordinateur.
2. Dans le dépôt GitHub `ouestpower-site`, ouvrir Add file > Upload files.
3. Envoyer/remplacer index.html, style.css, script.js et le dossier assets.
4. Cliquer sur Commit changes.
5. Attendre quelques minutes puis actualiser le site.

Ne pas envoyer uniquement index.html : les fichiers CSS, JavaScript et le dossier assets doivent rester ensemble.
